## 📚 Introduction

Object-Oriented Programming (OOP) is a programming paradigm that is based on the concept of **objects and classes**. It helps in organizing code in a structured and reusable way.

### 🔄 Procedural vs Object-Oriented Programming

| Procedural Programming  | Object-Oriented Programming         |
| ----------------------- | ----------------------------------- |
| Focuses on functions    | Focuses on objects                  |
| Top-down approach       | Bottom-up approach                  |
| Data is less secure     | Data is more secure (encapsulation) |
| Difficult to reuse code | Easy code reusability               |

## 🔤 Basic Concepts

### 📌 Data Types

* **Basic:** int, float, char, double
* **Derived:** array, pointer, structure
* **User-defined:** class, structure, union

### 📌 Tokens

Smallest unit in a program:

* Keywords (int, class, return)
* Identifiers (variable names)
* Constants (fixed values)
* Operators (+, -, *)

### 📌 Variables & Constants

* **Variable:** Value can change
* **Constant:** Fixed value (const keyword)

---

## 🧱 Object & Class

* **Class:** Blueprint of an object
* **Object:** Instance of a class

### Difference between Structure & Class

| Structure                     | Class                     |
| ----------------------------- | ------------------------- |
| Default access is public      | Default access is private |
| Used for simple data grouping | Used for OOP concepts     |

---

## 🔁 Control Structures

* **Sequence**
* **Selection:** if, switch
* **Iteration:** for, while, do-while

---

## 📦 Arrays & Strings

* **Array:** Collection of similar data types

## 🔧 Functions

### Types:

* Function definition

## 🏗 Constructors & Destructors

* **Constructor:** Initializes object
* **Destructor:** Cleans up memory

### Types of Constructors:

* Default constructor
* Parameterized constructor
* Copy constructor

---

## 🧠 Objects & Memory

* Memory is allocated when objects are created
* Each object has its own copy of data members

---

## ⚙ Static Members

* **Static Variables:** Shared among all objects
* **Static Functions:** Can access only static members

---

## ⚡ Inline Function

* Defined using `inline` keyword
* Improves execution speed by avoiding function call overhead

---

## 🤝 Friend Function

* Not a member of class
* Can access private and protected members
